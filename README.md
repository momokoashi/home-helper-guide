# 🏡 Home Helper Guide

A simple, phone-friendly guide for our home helper — covering daily tidying & laundry, and a library of healthy, protein-rich recipes (breakfast + lunch/dinner) using our usual ingredients.

## 📄 View it

- **Live page:** open `index.html` — or the GitHub Pages link for this repo.
- Works great on a phone, and prints cleanly (use the **Print / Save as PDF** button at the bottom).

## What's inside

- **General Info** — how the day works, tidy & laundry list, "nice to have" extras, where to buy ingredients, our protein sources, and a simple MyFitnessPal how-to.
- **Recipes** — batch-cooking ideas, plus breakfast (protein jelly, overnight oats, baked oatmeal cups, protein banana cake, warm oatmeal) and lunch/dinner options built around squid, shrimp, chicken breast and our soy protein.

Recipes are lightly seasoned (not too salty), protein-rich, and chosen to keep well for a few days. Each recipe links to its original source for reference.

_Single self-contained HTML file — no build step, no dependencies._
